# 0003. Офлайн-поставка и офлайн-карта

Статус: принято, 2026-09.

## Контекст

ВМ находится в сети предприятия, доступ в интернет — только по согласованию с ИБ.

## Решение

- Релиз — архив с образами Docker (`docker save`), `docker-compose.yml` и скриптами установки, бэкапа и
  восстановления. Установка и обновление — `install.sh`, без обращений в интернет.
- Карта на MapLibre GL. Подложки — файлы PMTiles (ортофото маркшейдерии, выгрузка OSM региона), которые
  раздаёт nginx с поддержкой range-запросов; список подложек бэкенд строит, читая заголовки файлов.
- Шрифты (глифы) и спрайты карты лежат в репозитории (`frontend/public/map-assets`).
- Внешние CDN не используются; Content-Security-Policy разрешает только собственный origin.

## Последствия

- Обновление карты — положить новый `.pmtiles` в `data/tiles/`.
- Размер архива с образом БД — около 1,3 ГБ; для обновлений без смены БД есть режим `--no-db-image`.

## Дополнение (2026-09): установка из GitHub

ВМ предприятия выходит на GitHub через корпоративный прокси. Для опытной эксплуатации добавлен второй способ:
CI после тестов на `main` публикует образы в ghcr.io (включая копию образа БД), ВМ ставится из git-клона и
обновляется `update.sh`. На ВМ по-прежнему ничего не собирается и не открывается входящих портов.
Runner GitHub Actions на ВМ отвергнут: репозиторий публичный, и чужой PR мог бы выполнить код внутри сети
предприятия. Офлайн-архив остаётся для площадок без интернета.
